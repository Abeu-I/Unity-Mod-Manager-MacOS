# Third-party components

This repository is an unofficial compatibility installer. It is not affiliated
with 7th Beat Games, Unity Technologies, Steam, or the upstream projects below.

## Unity Mod Manager

Unity Mod Manager is developed by newman55 and contributors:
https://github.com/newman55/unity-mod-manager

The installer downloads the official UMM package at install time. UMM binaries
are not stored in this repository.

## UnityDoorstop

The loader is based on the NeighTools UnityDoorstop projects:

- https://github.com/NeighTools/UnityDoorstop
- https://github.com/NeighTools/UnityDoorstop.Unix

Doorstop 4 is licensed under LGPL-2.1. The legacy Unix source used to reproduce
the compatibility dylib is included under `third_party/UnityDoorstop.Unix` with
its original notices and history attribution.

## A Dance of Fire and Ice

ADOFAI is property of 7th Beat Games. This project contains no game files. A
legitimate Steam installation is required.

## Mods

No third-party ADOFAI mods are bundled. Users download mods separately from
their respective authors.
