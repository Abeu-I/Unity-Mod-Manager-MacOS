Extends the game with Jipper’s visual resources and works alongside the Overlayer.

JA

JALib

The shared library required by Jipper mods. The installer keeps compatible versions together.

Install this before or alongside mods that list JALib as a dependency.

AP

Mac AutoPlay

A macOS-native testing tool that wraps ADOFAI’s built-in cross-platform autoplay mode.

Toggle with F8. Intended for local and custom-level testing, not competitive score submissions.

04 // RECOVERY

If the beat drops, start here.

UMM does not appear when I press Control + F10.+

On keyboards where F10 controls audio, press Control + Fn + F10. Also open the installer and run its diagnostic check to confirm the loader and mod are active.

Will Steam Workshop and achievements still work?+

Yes. Launch ADOFAI using the normal Steam Play button after installation. The in-bundle launcher preserves Steam’s game process and Steamworks connection.

Can I return to the vanilla game?+

Yes. The installer creates recoverable backups and includes a Restore Vanilla action. Your Mods folder is preserved during loader removal.

Does this work with every Unity game?+

No. This release is built and verified specifically for the Steam macOS version of A Dance of Fire and Ice.
