# Modern UMM UI

An ADOFAI-focused replacement for Unity Mod Manager's in-game window. It only
changes presentation: UMM remains responsible for loading mods, toggling them,
saving settings, and opening the window with Control+F10.

The replacement provides a clearer mod list, status summaries, dedicated mod
settings pages, an activity log, and an about/help page. If the custom renderer
throws an error, the patch disables itself and UMM's original window is used.
